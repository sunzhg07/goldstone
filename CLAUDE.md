# Goldstone — notes for Claude Code

Rust workspace for drawing many-body (CC, IMSRG, MBPT) and Feynman diagrams.

- `crates/goldstone-core`: model (`.gold` TOML), scene, geometry, LaTeX → diagram (`expr.rs`), function plots, templates.
- `crates/goldstone-export`: SVG/PDF/PNG/TikZ; labels typeset with typst + mitex (helpers for mitex output are in `labels.rs` `MITEX_PRELUDE`).
- `crates/goldstone-app`: egui editor (desktop and web). UI strings go through `i18n::t` / `i18n::tr`; every `t("…")` needs an entry in `i18n_zh.rs` (a test checks).
- `crates/goldstone-cli`: the `goldstone` binary. `crates/goldstone-web`: WebAssembly entry (trunk).
- Docs: `docs/MANUAL.md` (its key table is generated by `goldstone keys`; a test checks), `docs/DESIGN.md`, `docs/PARSER_PLAN.md`, README.

## LaTeX → diagram: strict rules, decided with the user

Do not add leniency or guessing; anything outside the rules is rejected with a message that says what to write.

- Operator = `X^{label}_{indices}`. Superscript optional, part of the name, shown as written. Subscript = fermion lines only; first half outgoing (bra), second incoming (ket). Braces required.
- Index = `a`, `a_1`, `a_{12}` (IMSRG rule also: single digits). Operator names never change how indices are read.
- CC rule (`Rule::Cc`, `cc-latex`): a–g particles, h–n holes, other letters general.
- IMSRG rule (`Rule::Srg`, `srg-latex`): all indices general unless an occupation factor (`n_a` hole, `\bar n_a` / `(1-n_a)` particle).
- Not drawn: `\sum`, permutations, coupling factors. Hermiticity is not used (such terms are rejected with a hint).
- Layout: particle/hole lines decide vertical order; an operator's vertices keep their written left-to-right order; external lines continue the column of the line they join.

## Working rules

- After changing code: `cargo fmt`, `cargo clippy --workspace --all-targets`, `cargo test --workspace`, and `cargo build --release -p goldstone` (the user runs the release binary). For web changes also `cargo check -p goldstone-app --lib --target wasm32-unknown-unknown`.
- Verify drawing changes by rendering (`goldstone cc-latex '…' -o x.png --background white`) and looking at the image. Editor screenshots: `GOLDSTONE_SHOTS=dir cargo test -p goldstone-app --test screenshots -- --ignored --test-threads=1`.
- Ask before pushing or tagging. Release: bump `version` in the workspace `Cargo.toml` and the crates' path dependencies, push `main`, then push the tag `vX.Y.Z` (the Release workflow publishes packages). The Web workflow deploys GitHub Pages from `main` only.
- After adding or updating dependencies: `python3 packaging/third_party_licenses.py -o THIRD_PARTY_LICENSES.md`.
